# Analytics Dashboard

## Project Description

This project is an Analytics Dashboard created using HTML, CSS, and JavaScript. It displays business analytics, performance metrics, revenue forecasts, demand predictions, and an ML Model Registry.

## Technologies Used

* HTML5
* CSS3
* JavaScript
  

## Features

* Dashboard layout with header and search bar
* Model Accuracy, Precision, Recall, and F1 Score cards
* Revenue Forecast chart
* Demand Prediction bar chart
* ML Model Registry table
* Search and clear search functionality
* Refresh button
* Responsive design for different screen sizes

## Project Structure

analytics-dashboard/

## How to Run

1. Download or clone the project.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. Explore the Analytics Dashboard.

## Learning Outcomes

* Understanding HTML page structure
* Styling layouts using CSS Grid and Flexbox
* Creating charts using JavaScript Canvas
* Handling events using JavaScript
* Implementing search functionality
* Creating responsive web pages
